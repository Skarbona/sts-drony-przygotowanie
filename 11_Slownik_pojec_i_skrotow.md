# 11 — Słownik pojęć i skrótów STS-01 / STS-02

> Słownik zbiera skróty i pojęcia, które pojawiają się w materiałach, quizie i przepisach. Przy nauce do egzaminu warto najpierw opanować sekcję **„Najważniejsze na egzamin”**, a resztę traktować jako ściągę podczas czytania tematów 01–08.

---

## Najważniejsze na egzamin

| Skrót / pojęcie | Rozwinięcie | Znaczenie w praktyce |
|---|---|---|
| **STS** | Standard Scenario | Unijny scenariusz standardowy w kategorii szczególnej. W tym materiale: **STS-01** i **STS-02**. |
| **STS-01** | Standard Scenario 01 | Operacje **VLOS** nad kontrolowanym obszarem naziemnym w środowisku zaludnionym. Dron C5 albo C3 + kit C5. |
| **STS-02** | Standard Scenario 02 | Operacje **BVLOS** nad kontrolowanym obszarem naziemnym w środowisku słabo zaludnionym. Dron C6. |
| **VLOS** | Visual Line of Sight | Lot w zasięgu wzroku pilota lub obserwatora UA. Pilot musi widzieć drona i oceniać jego orientację oraz otoczenie. |
| **BVLOS** | Beyond Visual Line of Sight | Lot poza zasięgiem wzroku pilota. W STS-02 wymaga spełnienia dodatkowych warunków, m.in. AO albo zaprogramowanej trasy. |
| **EVLOS** | Extended Visual Line of Sight | Rozszerzony VLOS z pomocą obserwatorów. Pojęcie częste w szkoleniach/NSTS, ale STS-02 formalnie używa AO. |
| **AO** | Airspace Observer | Obserwator przestrzeni powietrznej w STS-02. Wypatruje statków załogowych i ostrzega pilota. |
| **UA Observer / UAO** | Unmanned Aircraft Observer | Osoba pomagająca pilotowi utrzymać VLOS w STS-01. Nie jest tym samym co AO w STS-02. |
| **BSP / UA** | Bezzałogowy Statek Powietrzny / Unmanned Aircraft | Sam dron jako statek powietrzny. |
| **SBSP / UAS** | System Bezzałogowego Statku Powietrznego / Unmanned Aircraft System | Dron + stacja kierowania + łącza + wyposażenie. |
| **RP** | Remote Pilot | Pilot zdalny, czyli osoba wykonująca lot. |
| **Operator UAS** | UAS operator | Osoba/firma odpowiedzialna prawnie za operację, OM, oświadczenie, sprzęt i personel. Operator i pilot mogą być tą samą osobą, ale to różne role. |
| **OM** | Operations Manual | Instrukcja Operacyjna operatora. Wymagana dla operacji STS. |
| **ERP** | Emergency Response Plan | Plan reagowania awaryjnego, część OM. Określa, kto i co robi w sytuacji awaryjnej. |
| **MTOM** | Maximum Take-Off Mass | Maksymalna masa startowa drona: dron + baterie + payload + akcesoria. |
| **AGL** | Above Ground Level | Wysokość nad terenem. Limit STS 120 m jest liczony AGL. |
| **AMSL** | Above Mean Sea Level | Wysokość nad średnim poziomem morza. Używana w lotnictwie załogowym i AIP. |
| **FG** | Flight Geography | Obszar/przestrzeń, w której dron ma planowo lecieć. |
| **CV** | Contingency Volume | Bufor wokół FG na sytuacje odbiegające od normy. W STS: co najmniej +10 m poziomo i +30 m pionowo. |
| **OV** | Operational Volume | Przestrzeń operacyjna: Flight Geography + Contingency Volume. |
| **GRB** | Ground Risk Buffer | Bufor ryzyka naziemnego poza CV. Musi być wolny od osób postronnych. |
| **FTS** | Flight Termination System | System zakończenia lotu, np. spadochron, autorotacja albo inny mechanizm ograniczenia skutków fly-away. |
| **C2** | Command and Control | Łącze sterowania i kontroli między pilotem/stacją kierowania a dronem. |
| **DRI / Remote ID** | Direct Remote Identification / Remote ID | Zdalna identyfikacja drona emitowana lokalnie przez Bluetooth/WiFi. Wymagana w STS. |
| **Geo-awareness** | Świadomość stref geograficznych | Funkcja informująca drona/pilota o strefach, ograniczeniach i zakazach. |
| **Geofencing** | Ograniczenie geograficzne | Programowe ograniczenie lotu. Może być miękkie (ostrzeżenie) albo twarde (blokada). |
| **Geocaging** | Ograniczenie przestrzeni lotu | Twardy system ograniczający drona do zaprogramowanej przestrzeni. Istotny wymóg C6/STS-02. |
| **FailSafe** | Procedura awaryjna systemu | Zaprogramowane zachowanie po utracie łącza C2, np. RTH, hover, auto-land. |
| **RTH** | Return To Home | Automatyczny powrót do punktu Home. |
| **NOTAM** | Notice to Airmen / Notice to Air Missions | Depesza o czasowych zmianach w przestrzeni, infrastrukturze lub procedurach. Sprawdzać przed lotem. |
| **AIP** | Aeronautical Information Publication | Zbiór Informacji Lotniczych. Oficjalne dane o przestrzeni, lotniskach, procedurach. |
| **METAR** | Meteorological Aerodrome Report | Aktualny raport pogody lotniskowej, zwykle co 30 minut. |
| **TAF** | Terminal Aerodrome Forecast | Prognoza pogody dla lotniska, zwykle 24/30 h. |

## Klasy dronów i wymagania techniczne

| Skrót / pojęcie | Rozwinięcie | Znaczenie |
|---|---|---|
| **C0** | Klasa drona < 250 g | Najlżejsze drony, zwykle A1; bez Remote ID. |
| **C1** | Klasa drona < 900 g | A1, wymaga Remote ID i geo-awareness. |
| **C2** | Klasa drona < 4 kg | A2, wymaga m.in. trybu low-speed 5 m/s. |
| **C3** | Klasa drona < 25 kg | A3; może być bazą do C5 z accessories kit. |
| **C4** | Klasa drona < 25 kg bez automatyki | Modelarski sprzęt RC, bez Remote ID. |
| **C5** | Klasa dla STS-01 | Dron C5 albo C3 + kit C5; wymagane m.in. FTS, low-speed, Remote ID. |
| **C6** | Klasa dla STS-02 | Dron do BVLOS w STS-02; wymaga m.in. geocagingu i limitu prędkości 50 m/s. |
| **Accessories kit** | Zestaw akcesoriów | Zestaw podnoszący C3 do wymagań C5. |
| **Low-speed mode** | Tryb niskiej prędkości | Ograniczenie do 5 m/s, istotne w C2 i C5. |
| **UA Manual** | Instrukcja użytkownika drona | Dokument producenta z limitami, procedurami, FailSafe, konserwacją. |
| **IP rating** | Ingress Protection | Klasa ochrony przed pyłem i wodą, np. IP43, IP54. |
| **Legacy drone** | Dron bez klasy Cx | Dron wprowadzony/pracujący bez oznaczenia C0–C6. Może wymagać dodatkowej analizy zgodności. |
| **Payload** | Ładunek użyteczny | Kamera, LiDAR, termowizja, gimbal, megafon, dodatkowy czujnik itd. |
| **HLS** | Helicopter Landing Site (analogia) | W materiałach używane jako analogia do przygotowanego miejsca startu/lądowania. |

## Procedury, bezpieczeństwo i operacje

| Skrót / pojęcie | Rozwinięcie | Znaczenie |
|---|---|---|
| **Pre-flight** | Przed lotem | Planowanie, sprawdzenie stref, pogody, dokumentów, sprzętu i załogi. |
| **In-flight** | W trakcie lotu | Monitorowanie lotu, telemetrii, przestrzeni, ludzi, pogody. |
| **Post-flight** | Po locie | Wyłączenie, inspekcja, logi, debriefing, zgłoszenia. |
| **GO/NO-GO** | Decyzja startować / nie startować | Formalna decyzja pilota/operatora po checkliście i ocenie ryzyka. |
| **Abort** | Przerwanie misji | Zaplanowane kryterium zakończenia lotu, np. wiatr, osoba w GRB, statek załogowy. |
| **Lost link** | Utrata łącza C2 | Dron przestaje komunikować się z pilotem. Powinien wejść w FailSafe. |
| **Lost GPS / GNSS** | Utrata pozycjonowania satelitarnego | Dron może przejść w tryb Atti/manualny i dryfować z wiatrem. |
| **Fly-away** | Ucieczka drona | Dron oddala się niekontrolowanie mimo komend. Może wymagać FTS. |
| **Auto-land** | Automatyczne lądowanie | Dron ląduje sam w miejscu lub według procedury. |
| **Hover** | Zawis | Utrzymywanie pozycji w powietrzu. |
| **Home Point** | Punkt Home | Punkt powrotu RTH. Musi być poprawnie ustawiony przed lotem. |
| **Checklist** | Lista kontrolna | Ustrukturyzowany zestaw kontroli przed/in/po locie. |
| **Debriefing** | Omówienie po locie | Analiza, co poszło dobrze/źle, co poprawić w OM/procedurach. |
| **Stop Work Authority** | Prawo zatrzymania operacji | Każdy członek załogi może zgłosić zagrożenie i zatrzymać pracę. |
| **MAYDAY** | Wywołanie niebezpieczeństwa | Najwyższy priorytet w łączności, gdy istnieje bezpośrednie zagrożenie życia/statku. |
| **PAN-PAN** | Wywołanie pilności | Sytuacja pilna, ale bez natychmiastowego zagrożenia życia. |
| **Manned aviation** | Lotnictwo załogowe | Samoloty, śmigłowce, szybowce itd. Mają bezwzględne pierwszeństwo przed dronem. |
| **HEMS** | Helicopter Emergency Medical Service | Śmigłowiec ratownictwa medycznego. Zawsze ustępuj. |
| **DAA / D&A** | Detect and Avoid | Wykrywanie i unikanie ruchu/kolizji. Obowiązek pilota wspierany przez AO/ADS-B/Remote ID. |
| **ADS-B In** | Automatic Dependent Surveillance – Broadcast In | Odbiór sygnałów pozycji statków załogowych. |
| **ADS-B Out** | Automatic Dependent Surveillance – Broadcast Out | Nadawanie pozycji przez statek powietrzny. |
| **FLARM** | Flight Alarm | System antykolizyjny używany m.in. w szybownictwie. |
| **U-space** | Unijny system usług UTM | Zarządzanie ruchem dronów przez usługi cyfrowe. |
| **UTM** | Unmanned Traffic Management | Zarządzanie ruchem bezzałogowym. |
| **USSP** | U-space Service Provider | Dostawca usług U-space. |
| **CIS** | Common Information Service | Wspólna usługa informacyjna dla U-space. |
| **KSID** | Krajowy System Informacji Dronowej | Polski system informacji/obsługi operacji dronowych, w materiałach jako przyszłościowy/rozwijany kontekst. |

## Technika drona

| Skrót / pojęcie | Rozwinięcie | Znaczenie |
|---|---|---|
| **FC** | Flight Controller | Kontroler lotu, „mózg” drona. |
| **GCS / CS** | Ground Control Station / Control Station | Stacja kierowania: kontroler, tablet, laptop, oprogramowanie. |
| **RC** | Remote Controller / Radio Controller | Kontroler radiowy pilota. |
| **ESC** | Electronic Speed Controller | Regulator prędkości silnika. |
| **BLDC** | Brushless DC Motor | Silnik bezszczotkowy prądu stałego. |
| **PDB** | Power Distribution Board | Płytka rozdzielająca zasilanie. |
| **IMU** | Inertial Measurement Unit | Jednostka bezwładnościowa: akcelerometry + żyroskopy. |
| **GNSS** | Global Navigation Satellite System | Ogólne pojęcie dla GPS, Galileo, GLONASS, BeiDou. |
| **GPS** | Global Positioning System | Amerykański system nawigacji satelitarnej. |
| **Galileo** | Europejski GNSS | Europejska konstelacja nawigacji satelitarnej. |
| **GLONASS** | Rosyjski GNSS | Rosyjska konstelacja nawigacji satelitarnej. |
| **BeiDou** | Chiński GNSS | Chińska konstelacja nawigacji satelitarnej. |
| **RTK** | Real-Time Kinematic | Pozycjonowanie centymetrowe z poprawkami w czasie rzeczywistym. |
| **PPK** | Post-Processed Kinematic | Pozycjonowanie centymetrowe z poprawkami po locie. |
| **CORS** | Continuously Operating Reference Station | Stacja referencyjna GNSS. |
| **NTRIP** | Networked Transport of RTCM via Internet Protocol | Protokół przesyłania poprawek RTK przez internet. |
| **HDOP** | Horizontal Dilution of Precision | Wskaźnik geometrii satelitów dla pozycji poziomej. Niższy = lepiej. |
| **VPS** | Vision Positioning System | Pozycjonowanie optyczne z kamer/czujników w dół. |
| **ToF** | Time of Flight | Czujnik odległości mierzący czas powrotu sygnału. |
| **LiPo** | Lithium Polymer | Akumulator litowo-polimerowy, popularny w dronach. |
| **Li-ion** | Lithium-ion | Akumulator litowo-jonowy, często w „inteligentnych” bateriach. |
| **C-rating** | Współczynnik rozładowania | Informuje, jaki prąd bateria może bezpiecznie oddać względem pojemności. |
| **Wh** | Watt-hour | Watogodzina, energia baterii. Istotna w transporcie lotniczym. |
| **mAh** | milliampere-hour | Miliamperogodzina, pojemność baterii. |
| **S** | Series cells | Liczba ogniw szeregowo, np. 4S = 4 ogniwa. |
| **Kv** | RPM per volt | Parametr silnika BLDC: obroty na minutę na volt bez obciążenia. |
| **CW / CCW** | Clockwise / Counter-clockwise | Kierunek obrotu śmigła: zgodnie / przeciwnie do wskazówek zegara. |
| **T/W** | Thrust-to-Weight ratio | Stosunek ciągu do masy. W zawisie multirotora T/W = 1. |
| **VRS** | Vortex Ring State | Stan pierścienia wirowego przy szybkim opadaniu pionowym. |
| **Ground effect** | Efekt przyziemny | Dodatkowy ciąg/bliskość ziemi przy niskim zawisie/lądowaniu. |
| **EMC** | Electromagnetic Compatibility | Kompatybilność elektromagnetyczna. |
| **EMI** | Electromagnetic Interference | Zakłócenia elektromagnetyczne. |
| **Jamming** | Zagłuszanie | Celowe lub przypadkowe zakłócenie sygnałów radiowych/GNSS. |
| **OFDM** | Orthogonal Frequency-Division Multiplexing | Modulacja używana w nowoczesnych łączach cyfrowych. |
| **FHSS** | Frequency-Hopping Spread Spectrum | Technika przeskoku częstotliwości zwiększająca odporność łącza. |
| **RHCP / LHCP** | Right/Left Hand Circular Polarization | Polaryzacja kołowa anten. |

## Meteorologia

| Skrót / pojęcie | Rozwinięcie | Znaczenie |
|---|---|---|
| **VMC** | Visual Meteorological Conditions | Warunki meteorologiczne do lotów z widocznością. |
| **IMC** | Instrument Meteorological Conditions | Warunki „instrumentalne”, bez odpowiedniej widoczności dla VFR/VLOS. |
| **CAVOK** | Ceiling And Visibility OK | Widzialność ≥ 10 km, brak istotnych chmur poniżej 5000 ft i brak istotnych zjawisk. |
| **VIS** | Visibility | Widzialność pozioma. |
| **Ceiling** | Pułap chmur | Podstawa najniższej warstwy BKN/OVC. |
| **SIGMET** | Significant Meteorological Information | Ostrzeżenie o istotnych zjawiskach, np. burze, silne oblodzenie, turbulencja. |
| **AIRMET** | Airmen's Meteorological Information | Ostrzeżenie o mniej intensywnych zjawiskach dla lotnictwa. |
| **GAMET** | General Aviation Meteorological Forecast | Prognoza obszarowa dla lotów na niskich poziomach. |

## Człowiek, CRM i decyzje

| Skrót / pojęcie | Rozwinięcie | Znaczenie |
|---|---|---|
| **CRM** | Crew Resource Management | Zarządzanie zasobami załogi: komunikacja, role, decyzje, asertywność. |
| **SA** | Situational Awareness | Świadomość sytuacyjna: percepcja, zrozumienie, przewidywanie. |
| **IMSAFE** | Illness, Medication, Stress, Alcohol, Fatigue, Emotion/Eating | Szybka samoocena pilota przed lotem. |
| **PAVE** | Pilot, Aircraft, enVironment, External pressures | Model oceny ryzyka przed lotem. |
| **DECIDE** | Detect, Estimate, Choose, Identify, Do, Evaluate | Model podejmowania decyzji w sytuacji problemowej. |
| **5P** | Plan, Plane, Pilot, Passengers, Programming | Model regularnej oceny ryzyka podczas operacji. |
| **Sterile cockpit** | Sterylna kabina | W krytycznych fazach tylko rozmowy operacyjne. |
| **Get-there-itis** | Plan continuation bias | Presja ukończenia misji mimo pogarszających się warunków. |
| **Tunnel vision** | Tunel wzroku | Nadmierne skupienie na ekranie/obiekcie kosztem otoczenia. |
| **Autokinetic illusion** | Iluzja autokinetyczna | W nocy nieruchomy punkt świetlny może wydawać się poruszać. |
| **Yerkes-Dodson** | Krzywa stresu i wydajności | Za mało stresu usypia, umiarkowany pomaga, zbyt duży obniża skuteczność. |
| **Hazardous attitudes** | Niebezpieczne postawy | Anti-authority, impulsivity, invulnerability, macho, resignation. |

## Częste skróty, które mają kilka znaczeń

| Skrót | Znaczenie w tych materiałach | Uwaga |
|---|---|---|
| **FG** | Flight Geography albo Fog | W STS: Flight Geography. W METAR: Fog (mgła). Kontekst jest kluczowy. |
| **G** | Klasa G albo Gust | W przestrzeni: klasa G. W METAR: `G` oznacza porywy, np. `G25KT`. |
| **C** | Klasa C albo klasa drona C0–C6 | „Klasa C” przestrzeni to co innego niż „dron klasy C5”. |
| **D** | Klasa D albo EP D | Klasa przestrzeni kontrolowanej vs strefa niebezpieczna. |
| **AO** | Airspace Observer | Nie mylić z UA Observer w VLOS. |
| **OM** | Operations Manual | Nie mylić z „operatorem”; OM to dokument operatora. |
| **ID** | Remote ID / identyfikacja | Remote ID to system nadawania danych drona, a nie zwykła naklejka operatora. |

## Mini-checklista do nauki skrótów

- [ ] Umiesz odróżnić **operatora** od **pilota**.
- [ ] Umiesz rozwinąć: **VLOS, BVLOS, AO, UAO, MTOM, OM, ERP, FG, CV, OV, GRB, FTS, C2, DRI**.
- [ ] Wiesz, że **AGL** to nie **AMSL**, a limit 120 m w STS jest liczony **AGL**.
- [ ] Wiesz, że **FG** w STS to Flight Geography, ale w METAR **FG** oznacza mgłę.
- [ ] Wiesz, że **klasa C5/C6 drona** to nie to samo co **klasa C przestrzeni powietrznej**.
- [ ] Wiesz, gdzie szukać: **AIP**, **NOTAM**, **DroneTower/DroneRadar**, **ULC**, **PAŻP**.
