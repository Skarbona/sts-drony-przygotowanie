## Cheatsheet — kluczowe parametry

| Parametr | STS-01 | STS-02 |
|----------|--------|--------|
| **Reżim lotu** | VLOS | BVLOS (start/lądowanie VLOS) |
| **Klasa drona** | C5 (lub C3 + kit) | C6 |
| **MTOM** | < 25 kg | < 25 kg |
| **Wysokość max** | 120 m AGL | 120 m AGL |
| **Prędkość pozioma** | < 5 m/s | brak (max ≤ 50 m/s wg klasy) |
| **Otoczenie** | zaludnione (controlled ground area) | słabo zaludnione |
| **Odległość pilot–dron** | VLOS | 1 km bez AO / 2 km z AO |
| **Obserwator AO** | nie wymagany | wymagany do 2 km |
| **Remote ID** | aktywny + aktualny | aktywny + aktualny |
| **FTS** | wymagany (cecha klasy) | wymagany (cecha klasy) |
| **Materiały niebezpieczne** | zakaz | zakaz |
| **Ważność certyfikatu wiedzy** | 5 lat | 5 lat |
| **Ważność oświadczenia operatora** | 2 lata (lub do utraty kompletności) | 2 lata (lub do utraty kompletności) |
| **Koszt oświadczenia** | 50 zł | 50 zł |

| Egzamin | Wartość |
|---------|---------|
| Liczba pytań (bez A2) | **40** |
| Liczba pytań (z A2) | **30** |

## Jak korzystać

1. Przeczytaj **[09 — Organizacja egzaminu](./09_Organizacja_egzaminu.md)** — zrozum format.
2. Otwórz **[10 — Plan nauki i źródła](./10_Plan_nauki_i_zrodla.md)** — zaplanuj tygodnie.
3. Przerabiaj tematy 01–08 zgodnie z planem; każdy plik ma sekcję **„Pytania samosprawdzające"** i **„Pułapki egzaminacyjne"**.
4. Co tydzień rób mini-test z przerobionych tematów.
5. W ostatnim tygodniu — pełen test próbny w wybranym podmiocie wyznaczonym.

**Powodzenia!**
